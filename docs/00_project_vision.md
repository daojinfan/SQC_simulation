# 项目目标

## 总目标

构建一台最小但物理含义清晰的虚拟超导量子计算机，目标结构为 `2q1c2r`。

项目应尽量贴近真实实验室工作流：

```text
器件物理参数
  -> 哈密顿量构建
  -> 脉冲与电子学模型
  -> 实验执行
  -> 类测量数据
  -> 数据分析与参数更新
  -> 可视化与人工决策
```

第一版不追求通用平台，而是先把一台小型虚拟机器做可靠、做透明、做可检查。

## 目标器件

目标器件为：

```text
2q1c2r
```

组件包括：

```text
q1: 第一个量子比特
q2: 第二个量子比特
c : 可调耦合器
r1: q1 的读出谐振腔
r2: q2 的读出谐振腔
```

第一阶段的哈密顿量目标先聚焦在 `2q1c` 量子子系统。读出谐振腔在读出与测量模型阶段逐步加入。

## 核心原则

1. 物理模型必须显式、可检查。
2. 先打通一条可靠主线，再增加抽象。
3. 实验流程应支持人工操作和人工判断。
4. 每个重要设计决策和开发偏差都要记录。
5. 优先完成小而可靠的阶段，不追求大而未验证的架构。

## 第一版暂不追求的目标

第一版不急于支持任意芯片拓扑、多种器件家族、云端执行或通用 artifact 平台。

这些能力可以在 `2q1c2r` 虚拟机器可靠之后再考虑。

## 成功标准

项目成功时，用户应能够：

1. 用电容和结参数定义一台 `2q1c2r` 器件。
2. 生成并检查有物理意义的哈密顿量。
3. 运行基础频谱和校准实验。
4. 查看原始数据、拟合结果和推荐参数更新。
5. 人工接受或拒绝校准更新。
6. 使用校准后的参数仿真门操作，并检查末态或测量结果。
